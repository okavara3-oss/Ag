# AGREEN — نسخة قابلة للتثبيت

هذه نسخة PWA من تطبيق AGREEN، تشمل صفحة البرنامج وبنود الفحص والاستلام، وتدعم التثبيت على Chrome عند نشر الملفات عبر HTTPS.

## الرفع إلى مستودع GitHub Pages الحالي

1. فك ضغط ملف ZIP.
2. ارفع **محتويات مجلد AGREEN** إلى نفس مجلد النشر في المستودع، مع استبدال `index.html` وإضافة `manifest.json` و`sw.js` ومجلد `icons` كما هي.
3. انتظر اكتمال تحديث GitHub Pages وافتح رابط الموقع من جديد على HTTPS.
4. في Chrome على Android، افتح قائمة ⋮؛ يفترض أن يظهر خيار **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.

إذا لم يتغير الخيار فورًا، أعد تحميل الموقع بعد اكتمال النشر أو امسح بيانات الموقع/الذاكرة المؤقتة له ثم افتحه مجددًا.

## ملاحظات

- يجب أن تكون ملفات `index.html` و`manifest.json` و`sw.js` ومجلد `icons` في المستوى نفسه في مجلد النشر.
- يعمل التطبيق دون اتصال للملفات الأساسية بعد تحميله أول مرة؛ عرض المجسمات يحتاج اتصالًا لتحميل Three.js من CDN.
- تشغيله مباشرة بفتح الملف `index.html` من الجهاز لا يفعّل التثبيت؛ يجب فتح نسخة GitHub Pages على HTTPS.
